# CPS Digital Platform

หน้ารวมแอป CPS (Changan Production System) — login แล้วเห็นเฉพาะแอปที่ได้รับสิทธิ์

**ลิงก์:** https://changan-cps.github.io/cps-portal/

## ใช้งาน
- เปิดครั้งแรก (ยังไม่มี `config.json`) ระบบจะให้สร้างบัญชี Admin
- Admin กด **⚙️ ตั้งค่า Permission** เพื่อจัดการ แอป / ลิงก์ (แยก External Server / Factory Server), ผู้ใช้, สิทธิ์ และประกาศ
- กดชื่อตัวเองบนหัวเว็บเพื่อแก้ชื่อที่แสดง / รหัสผ่าน
- ติดตั้งเป็นแอปได้ (ปุ่ม "ติดตั้งแอป" มุมขวาล่าง หรือ iPhone: Share → เพิ่มไปยังหน้าจอโฮม)

## เผยแพร่การตั้งค่าให้ทุกเครื่อง
การแก้ไขในหน้าตั้งค่าจะอยู่ในเบราว์เซอร์ของคนแก้เท่านั้น จนกว่าจะ:
1. แท็บ **เผยแพร่** → ดาวน์โหลด `config.json`
2. อัปโหลด `config.json` ทับไฟล์เดิมใน repo นี้ (Add file → Upload files)

## หมายเหตุ
- รหัสผ่านเก็บเป็น hash (PBKDF2) ใน `config.json`
- Portal นี้ควบคุมเมนูที่มองเห็นเท่านั้น — ถ้ารู้ URL ของแอปโดยตรงยังเปิดได้
- แอปที่อยู่บน Factory Server (localhost / IP ภายใน) เปิดได้เฉพาะในเครือข่ายโรงงาน
